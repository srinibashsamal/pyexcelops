# pyexcelops

> Professional Excel reporting for pandas, made simple.

`pyexcelops` is a lightweight Python utility that helps you export one or more pandas DataFrames to a single, professionally formatted Excel workbook with minimal code.

It automatically applies consistent styling, auto-adjusts column widths, supports Excel tables, filters, text wrapping, row height optimization, column highlighting, and multi-sheet exports.

## Features

✅ Export multiple DataFrames to a single workbook

✅ Custom sheet names

✅ Professional header styling

✅ Automatic column width adjustment

✅ Optional Excel table creation

✅ Built-in AutoFilter support

✅ Column highlighting

✅ Freeze header row

✅ Text wrapping for large content

✅ Automatic row height adjustment

✅ Show or hide gridlines

✅ Graceful handling of empty DataFrames
